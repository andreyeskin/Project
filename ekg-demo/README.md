# ekg-demo

Маленький проект на чистом Python (без внешних зависимостей, только `pytest` для тестов):
отрисовка ЭКГ-полоски в SVG на миллиметровой сетке.

## Файлы

| Файл | Назначение |
|------|------------|
| `ekg.py` | Библиотека: `render_ekg_svg(values_mv, sample_rate_hz, speed_mm_s, gain_mm_mv)` строит SVG. |
| `demo.py` | Генерирует синтетическую ЭКГ (10 с, 60 уд/мин, 500 Гц) и сохраняет `demo_25.svg` и `demo_50.svg`. |
| `test_ekg.py` | Тесты геометрии: расстояние между R-зубцами, амплитуда, калибровочный зубец, viewBox. |
| `demo_25.svg`, `demo_50.svg` | Результат запуска `demo.py` при 25 и 50 мм/с. |

## Как это работает

Все координаты внутри SVG заданы **в миллиметрах**: `viewBox="0 0 W H"`, а
`width="Wmm" height="Hmm"`, поэтому при печати в масштабе 100 % одна клетка сетки
равна 1 мм, как на настоящей ЭКГ-бумаге.

* Сетка: тонкие линии через 1 мм, жирные через 5 мм.
* Скорость ленты `speed_mm_s`: 25 или 50 мм/с (другие значения отклоняются).
  Отсчёт `i` попадает в `x = x0 + i / fs * speed`.
* Усиление `gain_mm_mv`: по умолчанию 10 мм/мВ.
  Значение `v` мВ рисуется в `y = baseline - v * gain` (ось Y в SVG направлена вниз).
* Калибровочный зубец в начале полоски: прямоугольный импульс 1 мВ длительностью
  200 мс, то есть 10 мм в высоту и `0.2 * speed` мм в ширину (5 мм при 25 мм/с, 10 мм при 50 мм/с).
* Корневой элемент `<svg>` содержит атрибуты `data-speed-mm-s`, `data-gain-mm-mv`,
  `data-sample-rate-hz`, `data-baseline-mm`, `data-signal-x0-mm`, чтобы полоску можно
  было разобрать обратно (это используется в тестах через `parse_signal_points`).

## Использование

```python
from ekg import render_ekg_svg

svg = render_ekg_svg(values_mv, sample_rate_hz=500, speed_mm_s=25, gain_mm_mv=10)
open("strip.svg", "w", encoding="utf-8").write(svg)
```

Дополнительные параметры: `calibration=False` отключает калибровочный зубец,
`layout=EkgLayout(height_mm=..., margin_mm=..., baseline_mm=...)` задаёт геометрию,
`title="..."` заменяет подпись под сеткой.

## Запуск

```bash
cd ekg-demo
python3 demo.py          # создаст demo_25.svg и demo_50.svg
python3 -m pytest -q     # тесты (нужен pytest: pip install pytest)
```

## Что проверяют тесты

* При 25 мм/с и ЧСС 60/мин (RR = 1 с) R-зубцы в SVG отстоят друг от друга ровно на 25 мм;
  при 50 мм/с — на 50 мм. Допуск — один отсчёт сигнала.
* R-зубец амплитудой 1 мВ при 10 мм/мВ возвышается над изолинией на 10 мм.
* Калибровочный зубец имеет высоту 10 мм и ширину 5 мм при 25 мм/с.
* `viewBox` и `width`/`height` согласованы и выражены в мм; 1 с сигнала при 25 мм/с занимает 25 мм.
* Нестандартная скорость и пустой сигнал вызывают `ValueError`.
